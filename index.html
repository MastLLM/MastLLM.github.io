How a Mast model ships

Start from one base

Every specialist inherits Mast-1-Base, so the work on the foundation pays off across the whole family.

Teach one job

Data is filtered hard and checked by hand. Synthetic code exercises only count when their solutions run and pass.

Test it sealed

The test is written before training and never used to tune the model. Every number comes from questions it never saw.

Ship only if it wins

A specialist is released only when it beats larger general models at its job.
